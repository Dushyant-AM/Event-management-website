## Project Overview
D Events is a comprehensive event planning website designed to help users plan and organize various types of events 

- from birthdays and weddings to corporate parties and baby showers. The website aims to simplify the event planning process with a user-friendly interface and detailed information about different event types.

## Features

### 1. Navigation
- Responsive navbar with links to Home, About Us, Search, Events, Gallery, and Contact Us sections
  
- Mobile-friendly design with a collapsible menu

- HTML5
  
- CSS3 (Custom CSS and Bootstrap 5.3.2)

## File Structure
- HTML files for each event type (birthday.html, engagement.html, etc.)

-  Main page (ownevent.html)
   
- Login functionality (login.html)
  
- Custom styling (ownevent.css)
  
- Image assets for events and gallery

## Getting Started
1. Clone the repository

2. Open ownevent.html in your web browser to view the main page

3. Navigate through different sections using the navbar
